# Constant Jacobian 参数化机构仿真平台

面向 PRRR 三平移机构的 Python 参数化建模与仿真桌面应用。Python / NumPy 负责全部运动学、配重计算和动力学；PySide6 提供参数面板，内嵌离线 WebGL 提供不透明实体、深度遮挡和交互视角。无需启动服务器、联网或安装浏览器。

## 启动

在本目录打开终端：

```powershell
python -m pip install -r requirements.txt
python main.py
```

也可双击 `启动仿真平台.cmd`。需要 Python 3.10 或以上；当前验证环境为 Python 3.13.7、PySide6 6.10.1、NumPy 2.3.3。

## 使用

1. 在“参数建模”设置倾角、平台质量、连接半径、导轨轴线到零位中心距离和导轨总行程。三条支链分别设置近端/远端杆长、杆质量、滑块质量，以及 W2 / W3 反向配重臂长。
2. 点击“应用参数并计算配重”。修改尚未应用时会提示，仿真不会悄悄采用编辑中的参数。无法中心装配的参数会被拒绝，保留此前有效模型。
3. “计算结果”显示六个杆端配重、三个悬挂配重、绳路方向、J / G 与条件数。扫描按钮显示可达点云以及完整配重的残差检查。
4. “仿真控制”设置初始位移、XYZ 外力、重力、配重模式、质量比例、回中刚度 K 和阻尼 B；点击开始。默认人为回中 K=80 N/m、B=24 N·s/m，控制力为 −Kp−Bv；回中不是机构的固有特性。设 K=0 可关闭回中（阻尼仍保留），“偏置释放实验”也会自动将 K 置零。

默认回中参数针对完整配重模型：中心处等效模态质量约 1.36–1.76 kg，对应临界阻尼约 20.9–23.7 N·s/m，取 B=24 以减少回弹；偏移 10 mm 时弹性回中力为 0.8 N。从 [9,−8,12] mm 静止释放，约 0.73 s 后位置误差保持在 1 mm 内。修改杆件质量、配重或配重模式后可重新调节 K、B；这组默认值不保证所有自定义机构都接近临界阻尼。
5. 拖动白色末端球，通过 220 N/m 虚拟弹簧施加外力（鼠标力上限 12 N）；开始拖动自动启动仿真，松开撤去鼠标外力，不直接改变末端位置。按住鼠标越出三维视图时，通过指针捕获继续拖动施力，返回视图无需重新按下，仿真持续运行。只有松开、窗口失焦、系统取消拖动或丢失指针捕获时才撤去鼠标外力，仍不暂停仿真。“仿真控制”可选择随视角、XY、XZ、YZ 施力平面。粉色箭头表示总外力，粉色虚线连接鼠标目标。空白处拖动旋转，滚轮缩放，双击复位。白色虚线表示旋转轴和平移路径，按实体深度遮挡；标注可关闭。
6. 保存/打开 JSON 设计；导出理想配重报告和轨迹 CSV。CSV 包含时间、位移、速度、滑块位移、电机力、名义静平衡重力残差、动能、势能、总外力和鼠标力。该残差用于设计对比，假定配重绳张紧，不代表松绳时的实际支持力；界面另显示实际绳张力。报告中的质量为 100% 理想值，界面的配重比例影响实际参与仿真的全部九个配重。

`examples/default.json` 提供默认机构参数；`examples/asymmetric.json` 演示非等长、非对称质量和配重位置。

## 物理模型与适用范围

### 导轨参数化

三条导轨共用总行程 S 和距离 D。S 默认 55 mm，滑块坐标范围为 −S/2 至 +S/2；这是可用运动行程，不是包含滑块及端部安装余量的实物导轨长度。D 是导轨轴线（延长直线）到末端平台零位中心的垂直距离，默认约 144.260 mm，不是导轨中点到中心的直线距离。杆长约束可能进一步缩小工作空间。

Python 使用 SI 单位；先设置倾角和平台半径，再设置 D，最后创建或重建机构：

```python
from cj_sim.core import Design, Mechanism, Simulation

design = Design(alpha=35.26438968, platform_radius=0.068)
design.rail_total_travel = 0.060  # 总行程 60 mm，即 ±30 mm
design.rail_center_distance = 0.150  # 轴线到零位中心的垂距 150 mm
mechanism = Mechanism(design)  # 校验装配并重新计算几何、配重
simulation = Simulation(mechanism)
design.save('my_design.json')
```

为兼容旧 JSON，文件仍保存 `travel=S/2` 和 `anchor_distance=D−platform_radius·sin(alpha)`。后者是零位支链两端连接点的安装间距，并非 D。界面改变倾角或平台半径时保持所输入的 D；Python 中直接修改这些底层字段后，若要保持 D，需再次设置 `rail_center_distance`。应用参数后导轨显示、工作空间扫描和动力学限位使用同一套参数；几何上不能装配的组合会被拒绝。

内部统一使用 m、kg、s、N；界面长度用 mm、质量用 g。坐标以 Z 为竖直方向，末端平台只有三平移自由度。每条支链中的三个 R 轴相互平行并与其 P 轴平行，固定方向决定约束平面。调整杆长时保留此拓扑与轴线关系，因此 J 不依赖末端位置；杆长影响装配空间、配重和惯性。

`q = G p`，`J = G⁻¹`；`G` 的三行是 P 轴单位方向。倾角为 `atan(1/√2)` 时 J 正交、条件数为 1。末端电机力映射为 `τ = Jᵀ Fmotor`，此处 τ 单位是 N，不是旋转电机力矩。

各支链近端 C—B 长度 L2，远端 B—A 长度 L3。杆为均质细杆，质心固定在杆中点；配重是点质量，配重延长臂无质量，位置沿对应杆反向延长线设置。两级力矩平衡：

```
mW3 = m3 L3 / (2 r3)
mW2 = [m2 L2 / 2 + (m3 + mW3) L2] / r2
Mbranch = mSlider + m2 + m3 + mW2 + mW3
h_i = mPlatform J[2,i] + Mbranch_i G[i,2]
mH_i = |h_i|, s_i = sign(h_i)
zH_i = zH0_i - s_i q_i
```

每条支链局部质心等效固定于滑块后，悬挂配重通过绳路方向 s 抵消剩余重力。改变参数会重新求质量；运动时质量不变。默认 W2=225.362 g、W3=56.485 g，H1/H2=325.312 g、H3=650.623 g。

动力学：`M(p) p̈ + c(p,ṗ) = Fexternal − Kp − Bṗ − ∇U`。使用两点 Gauss 质量表示精确保留均质细杆平动和横向转动惯性；物体位置映射的解析一阶/二阶导数生成质量矩阵、势能梯度与惯性偏置。关闭重力仍保留所有已安装质量的惯性。固定 1/240 s 半隐式积分，时间以仿真时钟为准，不保证低性能设备的墙钟实时性。

滑轮和绳索理想、无质量、无摩擦。动态积分将悬挂配重的竖直坐标独立处理，以单向约束保证绳张力非负；松绳时配重自由运动，再次拉紧时通过非弹性冲量恢复约束。张紧阶段有 `zH = zH0 − s q`，因此 `T = mH(g − s q̈)`，不能误写成加号。松绳以虚线和文字标注；不模拟绳索摆动、弹性和实际下垂形状。

快速或大幅拖动碰到滑块行程/杆件装配边界时，采用非弹性限位约束，并在接近奇异位形前留出微小数值余量。仿真继续运行，保持鼠标按下并反向拖动即可离开边界；松开仍撤去鼠标力，不清除剩余惯性。只有非法参数或约束求解失败才暂停。限位及绳索重新拉紧会耗散碰撞动能，不能将这类状态与自由运动的能量守恒测试混用。

工作空间是离散采样的几何可达空间，不含自碰撞、配重/滑轮碰撞检查。杆件弹性、轴承摩擦和驱动器限流未建模。配重块外观尺寸用于辨识，不据此计算体积或转动惯量。默认尺寸/质量是演示参数，不声称是论文样机实测值。

## 代码与验证

- `cj_sim/core.py`：独立于 GUI 的参数、运动学、平衡计算、质量矩阵和积分器。
- `cj_sim/gui.py`：桌面参数编辑、仿真控制、曲线、项目与结果导出。
- `assets/`：仅负责显示 Python 输出的几何数据，不运行第二套动力学。
- `tests/test_mechanics.py`：非等长杆、非对称质量、虚功、恒定势能、惯性、释放、边界、能量与数据往返验证。
- `tests/gui_smoke.py`：应用内集成检查，覆盖参数重建、三维渲染、空间扫描、外力响应和 CSV，产物在 `outputs/qa/`。

```powershell
python -m unittest discover -s tests -v
python tests/gui_smoke.py
```

## 性能优化

动力学改用解析导数，避免每步重复构建九次机构；缓存结构常量与质量数据。三维使用 `gpu-renderer.js`：圆柱、球和配重块的网格只生成一次，通过 GPU 实例化更新位姿；线框使用线图元，点云仅在变化时上传。WebGL 直接显示在独立画布，不再逐帧复制到 2D 画布。旧 `solid-renderer.js` 留作原实现参考，不参与运行。

界面每次推进四个 1/240 s 子步。三维绘制与鼠标移动合并到浏览器动画帧；Python 最多保留一个待确认帧和一个最新状态，丢弃过时显示请求，物理积分和轨迹记录不因显示合并而丢失。数值面板以 10 Hz 更新。左侧独立的“仿真绘图”页包含末端 XYZ 位移（mm）和三个滑块驱动力 τ₁/τ₂/τ₃（N），横轴为仿真时间，显示最近 400 个记录点。驱动力为 `τ = Jᵀ(−Kp−Bv)`，不是鼠标外力或绳张力。绘图默认约 30 Hz 刷新（33 ms 定时器），可调 1–60 Hz；隐藏该页时不重绘，采样记录仍继续。刷新率不改变物理积分步长或 CSV 记录频率，实际绘制速度取决于系统负载。空间点云不会随每一帧重新序列化传输。

纯数值检查（不截图、不做视觉识别）：

```powershell
python tests/gui_smoke.py --no-screenshots
python tests/performance_check.py --seconds 20 --output outputs/performance.json
```

性能基准同时启用鼠标弹簧外力、完整配重、关节虚线、零件标注及空间点云，输出动力学耗时、界面更新耗时、浏览器动画帧间隔、绘制耗时及有界传输队列统计。帧率取决于实际显卡、窗口分辨率和系统负载；视觉与操作手感可在启动后手动确认。

直接用于参数研究：

```python
from cj_sim import Design, Leg, Mechanism

design = Design(legs=[Leg(proximal_length=.11, distal_length=.08), Leg(), Leg()])
mechanism = Mechanism(design)
print(mechanism.balance_report())
design.save('my_design.json')
```
